# Known limitations of HOSTS-based enforcement
# -----------------------------------------------------------------------------
# Some AI functionality is hosted as a URL path on a broader business domain.
# Windows HOSTS cannot block a URL path without blocking the entire hostname.
# Examples include services embedded within broad platforms such as search,
# productivity, social-media, or developer sites. Those require a URL-aware
# web filter or DLP control if Keystone later needs to block them selectively.
